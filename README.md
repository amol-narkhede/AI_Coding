# Contact Manager

This repository contains a simple contact manager desktop application written in Python with Tkinter. It can run on Windows and stores contact information in a local SQLite database.

## Features

- Import contacts from CSV files exported from Google Contacts or Microsoft Outlook.
- Add, edit, and delete contacts.
- Sort and search contacts.
- Data persisted using SQLite.

## Running

1. Ensure Python 3 is installed on your system.
2. Install required dependencies (only the standard library is needed).
3. Run the application:

```bash
python -m contact_manager.app
```

This will open the GUI where you can manage your contacts.
